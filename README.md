
# TaskMaster

A full stack task management application that helps users organize 
their work and life in one place.

## Live Demo
[View App](https://task-master-three-plum.vercel.app)

## Features
- User authentication with JWT
- Create, read, update and delete tasks
- Set deadlines and priority levels (Low, Medium, High)
- Search tasks in real time
- Deadline reminders via browser notifications

## Tech Stack
**Frontend:** HTML, CSS, JavaScript  
**Backend:** Node.js, Express  
**Database:** MongoDB  
**Authentication:** JWT, bcrypt  
**Deployment:** Vercel (frontend), Render (backend)

## Getting Started

### Prerequisites
- Node.js installed
- MongoDB account
